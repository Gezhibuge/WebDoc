这里是文档库，用来放网站教程、项目说明和更新公告，相比主站，这里更专注于把一件事讲清楚，所以排版会尽量简洁

## 内容范围

- 网站与项目相关的使用教程
- 功能说明、常见问题与排障记录
- 版本更新和公告

## 怎么更新

文章在 Pages CMS 后台以 Markdown 编写，保存后会提交到 GitHub，之后在 Cloudflare Pages 触发一次构建，新内容就会出现在本站

## 技术栈

Astro + Astro Theme Pure + Pages CMS + GitHub + Cloudflare Pages，主站 [www.gezhibuge.com](https://www.gezhibuge.com) 与本文件库相互独立
