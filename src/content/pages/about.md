这里是文档库，用来放网站教程、项目说明和更新公告，相比主站，这里更专注于把一件事讲清楚，所以排版会尽量简洁

## 这里能做什么

- 按分类整理教程、笔记和更新公告
- 用全文搜索快速找到某一段内容
- 通过标签筛选同一主题的文章
- 在文章底部顺序阅读同标签的上一篇和下一篇
- 用 Markdown 或 MDX 组件写出结构清晰的说明文档

## 怎么找内容

- 顶部搜索：输入关键词，也可以直接浏览全部文章
- 归档：按年份查看全部内容
- 标签：按主题筛选，例如教程、公告、说明
- 首页：查看最新文章和置顶内容

## 阅读体验

页面支持深色和浅色主题，切换时会平滑过渡，滚动带一点轻微惯性，鼠标指针也使用了自定义样式

## 更新方式

文章在 Pages CMS 后台以 Markdown 编写，保存后会提交到 GitHub，之后在 Pages CMS 侧栏点击“发布上线”，Cloudflare Pages 就会构建并发布新内容

## 技术栈

Astro + Astro Theme Pure + Pages CMS + GitHub + Cloudflare Pages，主站 [www.gezhibuge.com](https://www.gezhibuge.com) 与本文件库相互独立
