这是一篇格式说明，覆盖本文件库目前支持的 Markdown 语法和可嵌套组件。  
常用组件已经全局注册，写进阶文章时不需要手动 import。在 Pages CMS 里写文章时，可以直接复制本文的写法。

> 表格、任务列表、删除线和脚注由 GFM 提供，已经默认启用。  
> 普通文章用“文章”集合，需要组件的文章用“MDX 格式文章”集合。  
> 标有“仅 MDX”的章节必须使用进阶文章；没有标注的章节，普通 Markdown 也能直接使用。

## 一、文本格式

普通段落直接换行书写即可。支持：

- **粗体**
- *斜体*
- ~~删除线~~
- `行内代码`
- [普通链接](https://example.com)
- 键盘按键：<kbd>Ctrl</kbd> + <kbd>C</kbd>
- 高亮文本：<mark>重点内容</mark>

段落之间空一行。中文排版不需要手动加空格，浏览器会自动处理。

## 二、标题层级

```markdown
# 一级标题（文章正文里通常不用，标题已由 frontmatter 生成）
## 二级标题
### 三级标题
#### 四级标题
```

文章页面右侧的“目录”会自动读取二、三级标题。

## 三、列表与嵌套

### 无序列表

- 第一层
  - 第二层
    - 第三层
- 回到第一层

### 有序列表

1. 第一步
2. 第二步
   1. 子步骤
   2. 另一个子步骤
3. 第三步

### 任务列表

- [x] 已完成事项
- [ ] 未完成事项

### 列表里嵌套代码

- 安装依赖：

  ```bash
  npm install
  ```

- 启动开发服务器：

  ```bash
  npm run dev
  ```

## 六、表格

| 格式 | 写法 | 说明 |
| --- | --- | --- |
| 粗体 | `**文字**` | 强调 |
| 斜体 | `*文字*` | 语气 |
| 代码 | `` `code` `` | 行内代码 |
| 链接 | `[文字](https://example.com)` | 跳转 |

表格里也可以使用 **粗体**、`行内代码` 和 [链接](https://example.com)。
