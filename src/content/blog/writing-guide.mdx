这篇文档按 **效果 → 代码** 的顺序整理。先看实际显示效果，再复制下面的代码，改成自己的内容即可。

> 标有“仅 MDX”的章节需要把文章保存为“进阶文章（MDX）”。没有标注的章节，普通 Markdown 也能直接使用。
> 常用组件已经全局注册，不需要在文章顶部写 import。

## 一、文本格式

**效果**

普通段落直接换行书写即可。支持 **粗体**、*斜体*、~~删除线~~、`行内代码` 和 [普通链接](https://example.com)。

也可以使用键盘按键 <kbd>Ctrl</kbd> + <kbd>C</kbd>，以及高亮文本 <mark>重点内容</mark>。

**代码**

```md
普通段落直接换行书写即可。支持 **粗体**、*斜体*、~~删除线~~、`行内代码` 和 [普通链接](https://example.com)。

也可以使用键盘按键 <kbd>Ctrl</kbd> + <kbd>C</kbd>，以及高亮文本 <mark>重点内容</mark>。
```

**效果**

```md

```

## 十八、下载文件（仅 MDX）

**效果**

<Download
  title="Astro Theme Pure 横幅"
  note="PNG 图片 · 适合分享卡或文档插图"
  size="621 KB"
  href="/images/welcome/Astro-Theme-Pure.png"
/>

**代码**

```mdx
<Download
  title="Astro Theme Pure 横幅"
  note="PNG 图片 · 适合分享卡或文档插图"
  size="621 KB"
  href="/images/welcome/Astro-Theme-Pure.png"
/>
```

字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文件标题 |
| `note` | 否 | 备注、文件类型或用途 |
| `size` | 否 | 文件体积，例如 `621 KB` |
| `href` | 是 | 下载地址，支持站内 `/files/...` 或外部 HTTPS 链接 |
| `label` | 否 | 按钮文字，默认“下载” |
