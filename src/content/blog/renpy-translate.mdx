这是一份面向新手的 Ren'Py 游戏汉化教程，全程在 Windows 下操作

从下载游戏开始，依次走完解包、翻人名、生成翻译、翻译正文、精翻图片与字体、查缺补漏，最后打包发布

> 本教程以实战为主，不深究原理，参考了马老师的小课堂的 [Renpy 汉化](https://www.bilibili.com/video/BV1V39ZYFELC) 与 [Renpy 打包](https://www.bilibili.com/video/BV1wegbezEoJ) 两期视频，以及其他公开资料，个人精力有限，难免有疏漏，发现问题欢迎指出

<Aside type="note" title="关于本文">
  文中代码解析、报错分析部分有 AI 参与整理，实际操作步骤均为手工验证
</Aside>

不会写代码也没关系，需要用的代码都已经准备好，直接复制粘贴即可

不会改报错也不用怕，把报错信息配上文中给的提示词交给 AI，基本都能解决

## 二、准备工具

> 工欲善其事，必先利其器

这一章是基础环境准备，如果你不是第一次看这份教程，可以直接跳到第三章

### 需要的工具

| 工具 | 用途 | 是否必需 |
| --- | --- | --- |
| Bandizip | 解压游戏压缩包 | 必需 |
| Sublime Text | 编辑和搜索 rpy 文本 | 强烈建议 |
| Renpy 工具箱（马老师版） | 解包、提取额外文本 | 必需 |
| Ren'Py SDK 全量包 | 启动器与打包环境 | 必需 |
| FontCreator | 补全游戏字体 | 可选 |
| Adobe Photoshop | 修改图片与 UI | 推荐 |
| 剪映 | 处理需要汉化的视频 | 可选 |
| FormatFactory 格式工厂 | 视频转 webm | 可选 |

几个说明：

- **Bandizip**：游戏大多是压缩包，用它解压即可，WinRAR 也可以，能解压就行
- **Sublime Text**：为了**看得清** rpy 文件的语法高亮，也方便全局搜索报错，VS Code 同样可以，记事本不行，因为没有颜色区分
- **Renpy 工具箱（马老师版）**：作者封包的游戏需要它来解包，还能提取启动器识别不到的文本，可从 [马老师官网](https://www.maxlee7923.cn) 了解，只需下载这一个工具，**以最新版为准**
- **Ren'Py SDK**：官网各版本都能用，但更推荐马老师的全量包，打包时省去下载和配置插件的麻烦，至少下载 `8.3.7` 与 `8.5.2` 两个原版全量包；如果**不只汉化一款游戏**，两个都留着
- **FontCreator**：想同时保留原版英文字体和中文显示时用它，几乎是唯一顺手的选择
- **Photoshop**：处理游戏内的图片和 UI，虽然是可选项，但**强烈建议装上**
- **剪映**：极少数情况下需要汉化视频里的文字，一般 CG 中重要的位置作者都会留一张定格帧，所以用到的机会不多
- **格式工厂**：要改视频就必须用它转格式，剪辑软件导出的多为 `mp4`，而 Ren'Py 只认 `webm`

![Renpy 工具箱（马老师版）](/images/RenpyGameTranslate/008-tools.webp)

## 四、翻译人名与角色名

先翻人名，后期翻译正文时就不必逐个去猜谁在说话，译文也更连贯

打开 `game` 目录，随便选一个 `.rpy` 文件，右键 → `打开方式` → `Sublime Text`，如果弹出选择窗口，记得勾选 `始终`

![选择用 Sublime Text 打开](/images/RenpyGameTranslate/036-names.webp)

再从 `D:\Renpy\任派汉化包` 里把 `schinese` 文件夹复制到游戏的 `game\tl` 目录下

![把 schinese 放进 tl 目录](/images/RenpyGameTranslate/037-names.webp)

<Aside type="note" title="目录结构">
  多语言游戏在 `game\tl` 下可能有多个语言文件夹，这是正常的，如果只有一个名为 `None` 的文件夹，也正常
</Aside>

下面分三种情况处理人名

### 一般情况

回到 `game` 目录，打开 `script.rpy`

![game 目录下的 rpy 文件](/images/RenpyGameTranslate/038-names-general.webp)

按 `Ctrl + F` 搜索 `define`

![搜索 define](/images/RenpyGameTranslate/039-names-general.webp)

大概率会看到这种代码：

```python
define re = Character("Request", color = "#7a7a7a", size = 60, callback = dialog_type5)
define cl = Character("Clerk", color = "#7a7a7a", size = 60, callback = dialog_type2)
define b = Character("Boss", color = "#7a7a7a", size = 60, callback = dialog_type2)
```

以第三行为例：`b` 是这个角色的内部代号，`Boss` 才是对话里显示的名字

<Collapse title="这行代码具体是什么意思">

```python
# 定义一个代号为 b 的角色
define b = Character(
    "Boss",                  # 显示名称，出现在对话框上方
    color = "#7a7a7a",       # 名字颜色
    size = 60,               # 名字字号（像素）
    callback = dialog_type2  # 每次该角色说话时触发的回调，可能是音效、震动或特殊排版
)

# define：Ren'Py 关键词，用来定义游戏里的持久对象（角色、图像、变换等）
# Character：Ren'Py 内置类，用来创建对话角色
# 回调函数 dialog_type2 一般由作者在别处定义，与汉化无关，不要改
```

</Collapse>

这一片就是游戏里所有角色名，把它们整段复制下来，不确定范围就多复制一点

打开任意一个 AI 对话，例如 [DeepSeek](https://chat.deepseek.com/)，开启深度思考，然后把下面这段提示词发过去，再附上刚复制的代码：

```text
我是一名 Renpy 引擎的汉化者，需要你协助我开展汉化工作，接下来会给你一些 Python 代码

要求：
1. 这是人名翻译工作，要求你翻译以下代码中的人名
2. 请参考新华社标准译法等权威资料翻译外语人名
3. 翻译后通过代码框形式发给我，格式如下（注意每行前有四个空格）
    old "原文"
    new "译文"
4. 只发给我以上格式，不要发无关代码
5. 明白了请回复“明白，开始准备人名翻译”
```

拿到结果后，打开 `game\tl\schinese\base\name.rpy`，把翻译粘贴到文件末尾

```python
translate schinese strings:
    old "???"
    new "？？？"
    # 以上是这个文件自带的，不要动

    old "Request"
    new "请求"

    old "Clerk"
    new "店员"

    old "Boss"
    new "老板"
```

注意缩进：`old` 和 `new` 都要在 `translate schinese strings:` 下一级（通常 4 个空格），粘贴完检查一下译文，一般人名部分到这里就结束了

### 主角与可自定义名称

主角，或者任何允许玩家改名的角色，光在 `name.rpy` 里翻是不够的，游戏里往往还是显示原文

例如这个角色默认叫 `Haiiro`，玩家可以改名：

```python
    old "Haiiro"
    new "海伊罗"
```

翻译后进游戏发现没生效，找到对应句子，通常长这样：

```python
translate schinese label_guilt3_77591f92:

    # b "Hello [player], welcome"
    b "你好，[player]，欢迎光临"
```

把 `[player]` 改成 `[player!t]` 即可：

```python
translate schinese label_guilt3_77591f92:

    # b "Hello [player], welcome"
    b "你好，[player!t]，欢迎光临"
```

只改这一处，其他代码不动，之后每次遇到这种句子都要这样改

<Collapse title="为什么要加 !t">

Ren'Py 显示一行对话时，会先把 `[变量]` 替换成实际值，再拿整句去翻译表里找对应译文

所以 `[player]` 会被先替换成 `Alex`，翻译系统拿到的是「你好，Alex」，自然找不到翻译

加了 `!t` 之后，Ren'Py 会先翻译**变量名本身**，再把结果填进句子

```python
# 需要先在 strings 里定义变量名对应的译文
translate schinese strings:
    old "player"
    new "玩家名"

# 之后
b "你好，[player!t]"   # 显示：你好，玩家名
b "你好，[player]"     # 显示：你好，Alex
```

一句话记住：**玩家能改名的角色，一律用 `[名字!t]`**

</Collapse>

### 找不到 define 或找不到人名

分三种情况

**人名不在这个文件里**

按 `Ctrl + Shift + F` 打开多文件搜索，第一行输入 `define`，点 `...` → `添加目录`，目录选择游戏的 `game` 文件夹，然后点 `Find`

![添加搜索目录](/images/RenpyGameTranslate/041-names-missing.webp)

</div>

双击搜索结果即可跳转到对应位置，之后按一般情况处理

<div class="screenshot-grid not-prose">

![搜索结果](/images/RenpyGameTranslate/042-names-missing.webp)

![跳转到定义处](/images/RenpyGameTranslate/043-names-missing.webp)

![继续搜索其余角色](/images/RenpyGameTranslate/044-names-missing.webp)

</div>

**这个游戏根本没有角色名**

如果游戏里本来就不显示名字，自然不用翻

但不要把 `name.rpy` 删掉，之后的专有名词表可以直接写在这里，注意不是 `old`/`new` 格式的内容必须用 `#` 注释掉，否则会报错

```python
translate schinese strings:
    old "???"
    new "？？？"

### 一些专有名词注释
# Aegis Security = 伊吉斯安防
# Medika Biotech = 梅迪卡生物技术公司
# 情感干扰管控局
```

**作者用了特殊写法**

<Aside type="caution" title="前提">
  这种情况要在**生成翻译之后**才能搜到
</Aside>

如果游戏里明明有名字，但搜 `define` 搜不到，就换个思路：直接搜名字本身

比如名字是 `XiaoMing`，用 `Ctrl + Shift + F` 搜索，路径限定在 `game\tl\schinese`

如果搜出来的代码长这样：

```python
translate schinese label_guilt3_77591f92:

    # "XiaoMing | Hello, world"
    ""
```

说明作者没有用 `define` 定义角色，而是把名字硬写进了每句话里，这时有两条路：

- 如果这行是 `old`/`new` 格式，只能一句一句翻
- 如果只是纯文本，可以直接用 `Ctrl + H` 打开替换，填好原文与译文，点 `Replace All` 批量替换

![全局替换面板](/images/RenpyGameTranslate/045-names-missing.webp)

## 五、生成翻译与检查

这一章做两件事：把要翻译的文本抽出来，以及提前清掉明显的 bug

### 生成翻译

打开 Ren'Py 启动器，选中项目，点 `生成翻译`

![全选检查结果](/images/RenpyGameTranslate/055-lint.webp)

新建一个 AI 对话，先发这段提示词，再发检查结果：

```text
我是一名 Renpy 游戏的汉化者，现在使用 Renpy 启动器的 lint 检查了脚本，之后会发给你代码检查结果

要求：
1. 请告诉我这些结果产生的报错怎么修改
2. 引擎会自动修复的代码就不需要告诉我了（比如少一个 {/i} 结尾）
3. 请以新手都能听懂的方式告诉我怎么修改（原因 + 解决办法）
4. 明白了请回复“好的，请发给我 Lint 检查结果”
```

<Aside type="tip" title="一定要新开对话">
  不要接着之前的对话问，避免 AI 把无关上下文关联进来
</Aside>

常见结果大致分三类：

- **图片、视频、音频找不到**：多半是作者用了动态资源，不影响游戏运行，可以不管
- **文本标签未闭合之类的格式问题**：引擎运行时通常会自动纠正，改不改都行；如果影响了显示效果就必须改
- **其他问题**：按 AI 给出的办法改

## 七、翻译正文

从这里开始，路径和快捷键不再逐字重复，请默认你已知道「游戏根目录」「Ctrl + C/V」这些基本操作

### 译文放在哪

都在 `game\tl\schinese` 里

![schinese 目录结构](/images/RenpyGameTranslate/063-translate-location.webp)

需要翻译的是除 `base` 和 `fonts` 之外的所有 `rpy` 文件

### 两种翻译格式

翻译文件里主要有两种结构，第三种少见的格式放到第十章讲

**`old` / `new` 格式**

```python
translate schinese strings:

    old "Have you heard anything about the crisis?"
    new ""
```

- 第一行的注释表示这句原文出自哪个文件，不用管
- `old` 后面是原文
- `new` 后面是要填的译文，默认是空的

**`translate schinese` 翻译块**

```python
# game/script.rpy:192
translate schinese fp_visit_n1_06ea6bc8:

    # "Surprised to see me? Don't worry, I'm not here to rob you or anything."
    ""
```

- `translate` 声明这是一个翻译块
- `schinese` 是目标语言
- `fp_visit_n1_06ea6bc8` 是这段原文的唯一标识符，相当于身份证，不要改
- 缩进的注释是原文提示
- 引号里填译文

**缩进必须保持一致**，通常 4 个空格，缩进错乱是新手最常见的报错来源

两种格式的文件开头都可能出现这一行：

```python
# TODO: Translation updated at 2026-05-21 13:20
```

意思是「这个时间点之后的内容是新收集到的文本」，检测方法在 7.5 节

### 哪些不能翻，哪些必须改

**不能翻译的部分**

```python
    old "[icon_choice]Say nothing"
    new "[icon_choice]保持沉默"
```

```python
    # "Besides, I already {i}decided{/i}."
    "而且，我已经{i}决定{/i}了"
```

`{}` 里是显示效果（斜体、字号、颜色等），`[]` 里是变量或资源引用，**这些内容原样保留**

除了译文本身，不要往文件里塞额外内容，很容易引发报错

**必须处理的部分**

百分号 `%` 和英文引号 `"` 在 Ren'Py 里有特殊含义，直接留在译文里会导致报错，两种解法：

- 与原文保持一致，双写符号（如 `%%`），游戏里只会显示一个
- 换成中文符号，Ren'Py 不会解析中文标点

```python
    # "At least 10%% of the people attended the party"
    "至少有 10%% 的人参加了这场派对"

    # "\"That's what he said.\""
    "“他是这么说的”"
```

这两类问题 Lint 都能查出来，不用担心漏掉

另外，玩家可自定义的角色名记得改成 `[名字!t]`，这个 Lint 查不出来，因为语法上没毛病

批量排查可以用正则搜索，在 `game\tl\schinese` 范围内按 `Ctrl + Shift + F`，打开 `.*` 正则模式，搜索：

```text
\[([^\[\]]+)\]
```

![正则搜索变量插值](/images/RenpyGameTranslate/064-translate-rules.webp)

逐个确认是否需要加 `!t`

### 批量删除注释

原文注释看多了会干扰翻译，可以批量清掉

在 `game\tl\schinese` 范围内打开全局搜索，开启 `.*`，`Replace` 留空，`Find` 填：

```text
# .*|/\*[\s\S]*?\*/
```

点 `Replace` 全部替换

![批量删除注释](/images/RenpyGameTranslate/065-translate-comments.webp)

<Aside type="caution" title="注意备份">
  这一步不可撤销，建议先提交一次版本，或者整个目录复制一份备份
</Aside>

### 检查与补漏

检查分两部分：修 bug，和找漏翻

视觉小说的文本量很大，出错很正常，所以检查这一步不能省

- **Lint 检查**：在启动器里跑一遍，格式错误基本都能查出来
- **再次生成翻译**：和第五章一样再点一次 `生成翻译`，看看 `schinese` 里的文件修改时间有没有变

如果变了，说明 Ren'Py 又收集到了新文本，原因通常是某些句子的格式被改坏了，在庞大文本量下这很常见

![检查文件更新时间](/images/RenpyGameTranslate/066-translate-check.webp)

打开对应文件，找到 `# TODO: Translation updated at ...` 之后的内容，继续翻译即可

反复执行「改 bug → 清缓存 → 再生成翻译」，直到没有新文本、也没有必须修的问题

点确定

![粘贴选项设置](/images/RenpyGameTranslate/094-font.webp)

这时预览框应该能正常显示中文了，还有空白就说明有字形漏选了，补齐即可

![补全后的效果](/images/RenpyGameTranslate/095-font.webp)

![打开字形转换器](/images/RenpyGameTranslate/096-font.webp)

![调整字形效果](/images/RenpyGameTranslate/097-font.webp)

![导出设置](/images/RenpyGameTranslate/098-font.webp)

`文件` → `导出字体` → `导出电脑字体`（`Ctrl + Shift + E`）

![导出字体](/images/RenpyGameTranslate/099-font.webp)

![重命名为原字体名](/images/RenpyGameTranslate/100-font.webp)

![放回对应路径](/images/RenpyGameTranslate/101-font.webp)

```python
translate schinese python:

    # 系统设置字体
    gui.button_text_font = gui.interface_text_font
    # 系统默认字体
    gui.system_font = "tl/schinese/fonts/MiSans-Regular.ttf"
```

这样中文环境下所有没有单独指定字体的文本都会使用这个字体

## 十、收尾：查缺补漏

这是打包前的最后一道工序

前面已经做过一次文本收集，但总有些句子怎么都翻不到，比如运行游戏时还能看到英文，再生成翻译也收集不到新文本，这时就要手动补

假设这句没翻到：

```text
Where are you...Oh, found ya.
```

先在 `game` 目录里用 `Ctrl + Shift + F` 搜这句原文，找到它在哪个文件、哪一段，比如搜到：

```python
    pause
    play music2 dialog5 fadein 1
    d "Where are you...{w} Oh, found ya."
    stop music2 fadeout 1
    menu:
```

### 用 old / new 补漏

**最推荐的方式，** 在 `schinese` 目录下新建一个 `rpy` 文件，名字随意，第一行写：

```python
translate schinese strings:
```

然后按 `old` / `new` 格式补：

```python
translate schinese strings:

    old "Where are you...{w} Oh, found ya."
    new "你在哪……{w}哦，找到你了"
```

这种写法只影响这一句，安全、好维护

### 用 replace 补漏

**非常不推荐**，能不用就不用，属于没办法时的办法

同样新建一个 `rpy` 文件：

```python
init python:
    if preferences.language == "schinese":
        def replace_text(s):
            if not isinstance(s, str):
                return s
            s = s.replace("原文", "译文")
            return s
        config.replace_text = replace_text
    else:
        def replace_text(s):
            return s
        config.replace_text = replace_text
```

两个硬性限制：

- **只能处理纯文本**：带格式标签（`{}`、`[]`）的句子会被拆坏，必须拆开分别替换
- **长句写在前面**：短句写在长句前面会把长句拆碎，替换顺序必须从长到短

```python
init python:
    if preferences.language == "schinese":
        def replace_text(s):
            if not isinstance(s, str):
                return s
            s = s.replace("Where are you...", "你在哪……")
            s = s.replace("Oh, found ya.", "哦，找到你了")
            return s
        config.replace_text = replace_text
    else:
        def replace_text(s):
            return s
        config.replace_text = replace_text
```

## 十三、补充：汉化继承与清理

### 游戏更新后继承汉化

游戏更新后，把旧版本的 `schinese` 目录整体复制到新版本的 `tl` 目录下即可

接下来有两种做法：

- **直接生成翻译**：和之前一样点一次 `生成翻译`，Ren'Py 会把新增文本补进现有文件
- **归档旧译文再生成**：译文文件很多时更好用

第二种做法是先新建一个文件夹，把旧版本的译文全部移进去（**`base` 目录和非 rpy 文件不要动**），再生成翻译，新文本会以新的 rpy 文件出现在 `schinese` 下，只需要翻这些新文件

![归档旧译文](/images/RenpyGameTranslate/139-inherit.webp)

### 清理打包残留

打包会在启动器目录留下大量临时文件，项目多了很占空间

最省事的办法是用现成的清理脚本，**放在游戏根目录双击运行**即可

![清理脚本](/images/RenpyGameTranslate/140-cleanup.webp)

手动清理的话，删除这两处内容：

电脑端工程文件：

```text
D:\Renpy\renpy-8.3.7-sdk-All\tmp
D:\Renpy\renpy-8.5.2-sdk-All\tmp
```

安卓端工程文件：

```text
D:\Renpy\renpy-8.3.7-sdk-All\rapt\bin
D:\Renpy\renpy-8.5.2-sdk-All\rapt\bin
```

目录里的文件可以全部删除，注意别把整个 `tmp` / `bin` 文件夹本身删掉
